Move your health bars, hotbars and chat windows wherever you want them, set up chat shortcuts, and tidy your game settings. Everything stays on your own computer.

Bring in from

New here? Three steps.

  1. Get your settings out of the game. In DDO’s chat box type /ui layout save myui.layout and press Enter. The game tells you where it saved it — normally Documents \ Dungeons and Dragons Online \ UI \ layouts.
  2. Open it here. Use Open .layout above, or drag your .layout file anywhere onto this page. Nothing is uploaded — everything stays on your own computer.
  3. Change what you like, then save it back into that same folder. In game, type /alias clear and then /ui layout load myui.layout.

Not ready to use your own file? An example is already loaded, so you can click around freely — nothing here can affect your game until you save a file and load it yourself.

Heads up: this web page is not allowed to write a file ending in .layout. Save gives you ddo.layout.txt — just delete the .txt. Or use Copy .layout text and paste it into a text editor. Saving a copy of this page to your computer and opening it there writes ddo.layout directly, with no renaming.

What this does

DDO keeps three things in one settings file: where your bars and windows sit on screen, your chat shortcuts, and your game options. This editor opens that file, lets you change all three, and saves it back in the form the game expects.

Getting your file

In game, type /ui layout save myui.layout into the chat box. The game tells you where it saved it — normally Documents\Dungeons and Dragons Online\UI\layouts.

Putting it back

Save from here into that same folder, then in game type:

/alias clear /ui layout load myui.layout /alias list

Clear first, or you may hit the fifty-shortcut limit halfway through loading.

Writing a chat shortcut

A shortcut is swapped for a longer message before the game reads what you typed. That is why the message can carry a channel, colours, and even other shortcuts inside it.

Pick where it goes with the Where it goes box, and colour words by highlighting them and clicking a colour. You never need to type the codes yourself.

Handy file names

DDO understands two shorthands when you save: %c becomes your character name and %r becomes your resolution. So /ui layout save %c_%r keeps one layout per character per screen size, which matters because a layout built for one resolution rarely looks right on another.

With no name at all, the game uses Default_<resolution>.layout.

What the game will and will not accept

Moving things works. Anything the game saved a position for can be put where you like.

Resizing is hit and miss. Some panels resize happily, others enforce a minimum size, and a few ignore the change entirely and snap back when you load the file. Hotbars in particular take their size from how many slots they have, not from this file. If something springs back to its old shape in game, that is the client overruling you, not a mistake here.

Some windows are never saved at all — the main menu, the store, the expanded map and dialogue windows keep no position in the file, so they will not appear in this editor.

Always keep a backup of a layout you are happy with before experimenting. Saving under a second name costs nothing.

Layout checks

Every panel in the file is filed under a numbered Layout group, and the game only looks for each panel in its own group. The Layout checks card on the Screen layout tab flags panels filed in the wrong group, panels with no size, panels that run off the edge, and a hotbar saved twice. Nothing is changed unless you press the fix button beside the warning.

Colour profiles

The Game settings tab can set all the chat channel and combat text colours in one go. DDO default is copied from files the game itself wrote, so it is a true reset. A profile only changes colours that are already in your file, and it keeps each colour’s transparency. Save current as… keeps your own set in this browser so you can apply it to another character’s file.

Two mistakes this catches for you

One shortcut swallowing another. If you have both ;ro and ;roar, the shorter one can win and the longer never fires. The Checks panel warns you about every pair like that.

A stray space before coloured words. It is easy to end up colouring a blank space instead of the first letter. Colouring words by highlighting them here avoids it entirely.
